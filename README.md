# 🐶 바다 산책길 점프 러너

반려견 **바다(검은 푸들)**가 되어 해 질 무렵 동네 산책길을 달리는 쿠키런 스타일 원터치 러너입니다.
바다는 오른쪽을 향해 네 발로 달리고, 공중에서는 앞발을 모은 점프 자세로 날아오릅니다.
간식을 모으고, 악마 삼지창 간식을 먹으면 6초 동안 꼬마 악마로 변신해 **삼지창을 꼬리에 감아 들고** 장애물을 부숴버립니다.

## 🎮 바로 플레이

- **플레이 링크**: https://gombal82-hash.github.io/bada-walk-runner/
- 아이폰 사파리에서 위 주소를 열면 설치 없이 바로 실행됩니다.
- 홈 화면에 추가하면 전체 화면 앱처럼 즐길 수 있습니다(사파리 → 공유 → 홈 화면에 추가).

## 🕹 조작법 (쿠키런식 두 손가락)

| 입력 | 동작 |
|---|---|
| 화면 **오른쪽** 탭 · `Space` · `↑` · `W` | 점프 |
| 공중에서 한 번 더 | **2단 점프** |
| 화면 **왼쪽** 꾹 누르기 · `↓` · `S` | **슬라이드** — 납작 엎드려 미끄러지며 날아오는 장애물 아래로 통과 |
| 공중에서 왼쪽 꾹 | 급강하 (빠르게 착지) |
| 게임 오버 화면 탭 | 즉시 다시 시작 |
| 우측 상단 🔊 | 효과음 켜기 / 끄기 |

- 세로로 들고 있어도(회전 잠금 포함) 화면이 90° 돌아가 가로로 플레이되며, 이때도 **게임의 왼쪽/오른쪽**으로 터치 구역이 정확히 나뉩니다.

## ✨ 게임 요소

- **땅 장애물**: 물웅덩이 · 낙엽 더미 · 소화전 · 풀숲 — 점프/2단 점프로 넘습니다.
- **날아오는 장애물**: 까마귀 · 드론 — 서서 달리면 부딪히고, **슬라이드로 아래를 통과**합니다.
- **간식 패턴**: 점프 포물선 아치 · 2단 점프 높은 아치 · 슬라이드 일직선 줄 · 코인 러시가 거리 기준 박자로 이어집니다.
- **아이템**: 뼈다귀 +10 · 황금 간식 +50 · 자석 간식(7초 동안 간식 흡입) · 악마 삼지창 +20 후 피버.
- **꼬마 악마 피버**: 6초 무적, 부딪힌 장애물 파괴(+25), 점수 2배, 몸통 크기 **1.2배**, 흐르는 속도 **1.5배**.
- **콤보**: 간식을 3.6초 안에 이어 먹으면 최대 x5 배수.
- **하트 3개**: 한 번 부딪히면 하트 1개 감소 + 1.5초 무적.
- **최고 점수**: 기기에 저장되어 다음 판에도 이어집니다.

## 🛠 기술

- `index.html` 단일 파일(약 307KB) — 외부 요청 0건, 오프라인에서도 실행됩니다.
- Canvas 2D + `requestAnimationFrame`, `devicePixelRatio` 대응. 프레임 시간은 0.05초로 클램프하고 물리는 1/120초 서브스텝으로 돌립니다.
- 사운드는 Web Audio API로 실시간 합성(음원 파일 없음).
- **배경 심리스**: 구름·산·나무·전봇대·울타리·자갈·풀잎 등 모든 반복 요소를 "전역 슬롯 번호의 해시"로만 그려서, 스크롤이 한 주기를 되감겨도 그림이 픽셀 단위로 같습니다(경계에서 튀는 끊김 0건 — 자동 측정 42만 건).
- **가로 화면 기준 배율**(아이폰 가로 844×390·932×430, PC 가로 창)로 설계, 바다 키는 화면 높이의 **18.3%**. 세로로 들면 화면을 90° 돌려 그대로 가로로 플레이됩니다. `touch-action:none`으로 스크롤·확대 차단, 노치 안전영역(`env(safe-area-inset-*)`) 대응.
