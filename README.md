# 🐶 바다 산책길 점프 러너

반려견 **바다(검은 푸들)**가 되어 네 가지 산책길을 차례로 완주하는 쿠키런 스타일 원터치 러너입니다.
바다는 오른쪽을 향해 네 발로 달리고, 공중에서는 앞발을 모은 점프 자세로 날아오릅니다.
왼쪽 화면을 꾹 누르면 **배를 바닥에 깔고 앞발·뒷발을 쭉 뻗은 전용 슬라이드 포즈**로 미끄러집니다.
간식을 모으고, 악마 삼지창 간식을 먹으면 6초 동안 꼬마 악마로 변신해 **삼지창을 꼬리에 감아 들고** 장애물을 부숴버립니다.
**한 스테이지를 완주하면 주현 님이 올려주신 바다 사진이 폴라로이드 카드로 짠!** 하고 나타납니다.

## 🎮 바로 플레이

- **플레이 링크**: https://gombal82-hash.github.io/bada-walk-runner/
- 아이폰 사파리에서 위 주소를 열면 설치 없이 바로 실행됩니다.
- 홈 화면에 추가하면 전체 화면 앱처럼 즐길 수 있습니다(사파리 → 공유 → 홈 화면에 추가).

## 🕹 조작법 (쿠키런식 두 손가락)

| 입력 | 동작 |
|---|---|
| 화면 **오른쪽** 탭 · `Space` · `↑` · `W` | 점프 |
| 공중에서 한 번 더 | **2단 점프** (높은 덤불·파라솔·바리케이드를 넘을 때 필수) |
| 화면 **왼쪽** 꾹 누르기 · `↓` · `S` | **슬라이드** — 배를 깔고 쭉 미끄러지며 날아오는 장애물 아래로 통과 |
| 공중에서 왼쪽 꾹 | 급강하 (빠르게 착지) |
| 클리어 카드의 `다음 스테이지 도전 →` | 다음 맵으로 (점수 이어짐) |
| 우측 상단 🔊 | 효과음 켜기 / 끄기 |

- 세로로 들고 있어도(회전 잠금 포함) 화면이 90° 돌아가 가로로 플레이되며, 이때도 **게임의 왼쪽/오른쪽**으로 터치 구역이 정확히 나뉩니다.

## 🗺 스테이지 (한 판 = 한 스테이지)

| 스테이지 | 테마 | 목표 | 속도 | 실측 클리어 시간* |
|---|---|---|---|---|
| **1** | 햇살 공원 산책길 — 초록 나무·울타리·모래길 | 1,100 m | 1.00× | 36.2초 |
| **2** | 노을빛 해변 산책로 — 주황·분홍 노을, 바다와 야자수 실루엣 | 1,300 m | 1.15× | 37.3초 |
| **3** | 별빛 야간 도심 산책로 — 별·초승달·빌딩 불빛·가로등 | 1,600 m | 1.28× | 41.3초 |
| **4** | 무지개 구름 하늘길 — 파스텔 하늘·무지개 아치·구름길 | 1,800 m | 1.40× | 39.6초 |
| **∞** | 4개 완주 후 해금되는 **보너스 무한 런** | 끝없음 | 1.40× | — |

\* 844×390 가로 화면·장애물 회피 없이 달린 기준(무적 상태 측정). 실제 플레이에서는 점프·슬라이드 타이밍에 따라 조금 달라집니다.

- 상단에 **`STAGE n · 맵 이름` 배지 + 진행률 바(🏁 결승 깃발 · 🐾 진행 마커 · 남은 거리 m)**가 표시됩니다.
- 클리어하면 **STAGE CLEAR! 카드**: 축하 폭죽 + 점수/최고 콤보 + **실제 바다 사진 폴라로이드**(따뜻한 캡션) + `다음 스테이지 도전 →` / `이 스테이지 다시 달리기`.
- 4개를 모두 완주하면 **ALL STAGES CLEAR** 엔딩 카드와 함께 보너스 무한 런이 열립니다.
- 해금한 스테이지와 마지막 선택은 `localStorage`에 저장되어, 타이틀 화면에서 **Stage 1~4(잠긴 맵은 🔒)** 중 골라 시작할 수 있습니다.

## ✨ 게임 요소

- **지상 장애물**: 물웅덩이 · 낙엽 더미 · 소화전 · 풀숲 · **굴러오는 비치볼**(스스로 왼쪽으로 굴러옴) · **높은 덤불/비치 파라솔/야간 바리케이드/사탕 구름 기둥**(키 1.12 sH — **2단 점프**로만 통과) · **모래 바위·불가사리** · **꼬물꼬물 게** · **라바콘**.
- **공중 장애물**: 까마귀 · 드론 · **갈매기** — 서서 달리면 부딪히고 **슬라이드로 아래를 통과**합니다. **2~3연속 편대**는 슬라이드를 길게 꾹 유지해야 지나갈 수 있고, **점프→착지→슬라이드 콤보** 구간도 나옵니다.
- **간식 패턴**: 점프 포물선 아치 · 2단 점프 높은 아치 · 슬라이드 일직선 줄 · 코인 러시(스테이지 4 간식 러시 구간).
- **아이템**: 뼈다귀 +10 · 황금 간식 +50 · 자석 간식(7초 흡입) · 악마 삼지창 +20 후 피버.
- **꼬마 악마 피버**: 6초 무적, 모든 장애물 파괴(+25), 점수 2배, 몸통 크기 **1.2배**, 흐르는 속도 **1.5배**, 슬라이드도 전용 악마 슬라이드 포즈.
- **콤보**: 3.6초 안에 이어 먹으면 최대 x5 배수. **하트 3개**, 피격 시 1.5초 무적.

## 🛠 기술

- `index.html` 단일 파일 **576KB** — 외부 요청 0건, 오프라인에서도 실행됩니다.
- Canvas 2D + `requestAnimationFrame`, `devicePixelRatio` 대응. 프레임 시간은 0.05초로 클램프하고 물리는 1/120초 서브스텝으로 돌립니다.
- 사운드는 Web Audio API로 실시간 합성(음원 파일 없음). 클리어 팡파르 포함.
- **배경 심리스**: 구름·산·나무·야자수·빌딩·파도·자갈·풀잎 등 모든 반복 요소를 "전역 슬롯 번호의 해시"로만 그려서, 스크롤이 한 주기를 되감겨도 그림이 픽셀 단위로 같습니다. **4개 스테이지 × 8초 × 2해상도 자동 측정에서 끊김 0건**.
- **슬라이드 전용 포즈**: 달리기 프레임을 세로로 눌러 찌그러뜨리던 방식을 없애고, 배를 바닥에 깐 전용 스프라이트(가로:세로 ≈ 2.2:1)를 0.56 sH 높이로 그립니다. 히트박스 높이가 0.73 sH → 0.27 sH로 줄어 공중 장애물 아래를 통과합니다.
- **가로 화면 기준 배율**(아이폰 가로 844×390·932×430, PC 가로 창)로 설계, 바다 키는 화면 높이의 **18.3%**. 세로로 들면 화면을 90° 돌려 그대로 가로로 플레이됩니다. `touch-action:none`으로 스크롤·확대 차단, 노치 안전영역(`env(safe-area-inset-*)`) 대응.

## 🖼 완주 사진 바꾸기

`game-build/photos.py`가 `attachments/…` 폴더의 사진을 골라 줄이고 `game-build/photos.json`을 만듭니다.
새 사진을 올리면 아래처럼 다시 만들고 `build.py`를 돌리면 게임에 그대로 들어갑니다.

```
python3 game-build/photos.py --count 6 --folder attachments/2026-11-20
python3 game-build/build.py
```
